# Llama.cpp examples

| Image | Description | README |
|-------|-------------|--------|
| `base` | Llama.cpp image adapted for Dispersed (`SSH_PUBKEY` passthrough) | [README](base/README.md) |
| `basic_auth` | The same as base but with basic auth and an nginx proxy (`SSH_PUBKEY` passthrough) | [README](basic_auth/README.md) |
| `preload` | The same as basic_auth but with provision for preloading models into the image (`SSH_PUBKEY` passthrough) | [README](preload/README.md) |
| `access_code` | The same as preload but gets a container access code from Dispersed to do basic auth (`SSH_PUBKEY` passthrough) | [README](access_code/README.md) |
